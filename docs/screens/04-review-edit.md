# Preview & edit (manual)

## Purpose

Mandatory step before Save: adjust quad, filters, rotate, reorder; then commit pages.

## Entry / exit

- Entry: after capture, import, or suggest
- Exit: Save → library (+ quota); Discard → confirm

## Controls

- Drag 4 corners; Reset quad; Apply warp; Undo to original
- Rotate 90°
- Filters: Color, Gray, B&W, **Document / Remove shadow**
- Batch filmstrip: reorder, delete page, add more (camera/import)
- Rename before save
- Save blocked by paywall if not enough quota
