# Export / share / print

## Purpose

Export Images, searchable PDF, or DOCX; system share; print.

## ASCII

```
┌─────────────────────────┐
│ ←  Export               │
│                         │
│  Format                 │
│  ( ) Images (JPEG)      │
│  (•) PDF (searchable)   │
│  ( ) DOCX               │
│                         │
│  Pages: All (4)         │
│                         │
│  [ Print ]              │
│  [ Share… ]             │
└─────────────────────────┘
```

## Acceptance

- PDF includes OCR text layer
- DOCX embeds page images + OCR text in order
- Share uses system sheet; Print uses system print UI
