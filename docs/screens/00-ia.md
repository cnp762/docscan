# Information architecture

## Purpose

Map primary navigation and feature entry points (English UI).

## Flow

```
Onboarding (EN)
    → Home / Library
         ├─ Suggest last 7 days  (library permission)
         ├─ Capture (single|batch) ─┐
         ├─ Import (picker/files) ──┼→ Preview/Edit → Save → Library
         ├─ Search / Filter
         ├─ Doc / Batch Detail
         │      ├─ Edit (no +quota)
         │      ├─ Copy OCR
         │      ├─ Export (Images | Searchable PDF | DOCX)
         │      ├─ Print / Share
         │      └─ Backup
         ├─ Paywall
         └─ Settings
```
